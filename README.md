# Ni uno menos — edición novela gráfica

Juego narrativo educativo sobre prevención del acoso escolar, dirigido a alumnado de secundaria.

## Jugar

Abre `index.html` en un navegador moderno o sirve la carpeta desde un servidor web estático (por ejemplo, GitHub Pages). No requiere compilación, cuentas ni envío de datos a un servidor.

## Modos

1. **Su semana:** vive cinco días desde la perspectiva de Noa.
2. **Desde la clase:** decide como Mar, testigo de los hechos. Sus elecciones pueden afectar una nueva partida de «Su semana».
3. **Reparar:** participa en un círculo voluntario y supervisado de reparación.

La lógica, las decisiones y los recursos de ayuda proceden de la versión 1.1. Esta edición incorpora viñetas de la biblia artística aprobada, con respaldo de escenas SVG originales cuando falta una imagen.

## Estructura

- `index.html`: aplicación completa, estilos y guion.
- `assets/`: viñetas optimizadas por escena (`s1_`, `s2_`, `s3_` para el primer modo; `m2_`, `m3_` para los otros dos).

## Consideraciones

- El proyecto es un recurso educativo, no sustituye la actuación de los equipos docentes ni los protocolos de protección.
- Las ilustraciones son una integración inicial del storyboard; algunas se reutilizan en desenlaces alternativos. Se deberán revisar las correspondencias entre imagen y texto en una siguiente revisión artística.
- No se asigna licencia de reutilización al código ni al arte hasta que la persona titular decida las condiciones.

## Privacidad

Los datos de partida se gestionan en el navegador. Comprueba el comportamiento final de almacenamiento y exportación antes de desplegarlo para uso institucional.
